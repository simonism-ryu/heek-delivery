# 또렷이 배달

히크 렌즈가이드 연구소의 하루를 담은 작은 행성 배달 게임입니다. 배달부가 되어 안경 쓰는 게이머 하늘이에게 VR 렌즈가이드를 전하고, 동네 사람들에게 VR 꿀팁을 모아 VR 수첩을 채웁니다.

**플레이**: https://simonism-ryu.github.io/heek-delivery/

## 조작

| 기기 | 이동 | 말 걸기 | 수첩 |
|---|---|---|---|
| 휴대폰 · 태블릿 | 화면 아무 곳이나 끌기 | 화면 아래 버튼 | 오른쪽 위 수첩 버튼 |
| 컴퓨터 | WASD · 방향키 | Space · Enter | B |

글자 크기와 소리(배경음 · 효과음 · 음성)는 시작 화면과 게임 중 오른쪽 위 설정 버튼에서 바꿉니다.

## 이야기

1. 히크 연구소에서 렌즈가이드 챙기기
2. 하늘이네에 배달하기
3. 또렷안경원에서 데모렌즈의 인점 · 난시축 표시를 보고 축 맞추기
4. 가공된 렌즈가이드를 하늘이에게 전하기

게임 속 처방 수치와 인물 · 가게 이름은 게임용 예시입니다. 도수렌즈는 안경원에서 검안하고 맞춥니다.

## 만든 방식

- 파일 하나(`index.html`)로 동작합니다. 3D는 three.js r128(CDN), 소리는 Web Audio로 합성, 음성은 기기의 한국어 목소리(Web Speech)를 씁니다
- 크롬 · 삼성 인터넷 · 사파리 같은 웹 브라우저에서 열어 주세요. 스크립트를 실행하지 않는 HTML 뷰어 앱에서는 동작하지 않습니다
